The History of JavaScript

JavaScript was created in 1995 by Brendan Eich while he was working at Netscape Communications. It was originally developed in just 10 days and first appeared in the Netscape Navigator browser.

The language was initially called Mocha, then changed to LiveScript, and finally named JavaScript to capitalize on Java's popularity at the time, despite the two languages being completely different.

Key Milestones

1995 - Brendan Eich creates Mocha in 10 days at Netscape. Renamed to LiveScript, then JavaScript.
1996 - Microsoft releases JScript, a reverse-engineered version for Internet Explorer 3.
1997 - JavaScript was standardized under the name ECMAScript by ECMA International to stop browser wars.
2009 - ES5 released. Node.js created by Ryan Dahl, bringing JS to the server.
2015 - ES6/ES2015 released. Major update adding classes, modules, arrow functions =>, let/const, and promises.
2016+ - Yearly releases: ES2016, ES2017, etc. Adding features like async/await, optional chaining, and more.

JavaScript Today

Since standardization, it has evolved through several versions, adding features like classes, modules, and arrow functions. Today, JavaScript powers the web — used for front-end frameworks like React, Angular, and Vue, mobile apps with React Native, and even on the server with Node.js.

From a 10-day hack to the world's most popular programming language — JS now runs everywhere from browsers to robots.
