JavaScript Fundamentals

Reserved keywords, output methods, variables, data types, NaN, undefined, and object practice

1. 15 Reserved JavaScript Keywords

Keywords are words JavaScript reserves for syntax. You cannot use them as variable names.

var

Function-scoped variable declaration. Can be redeclared.

let

Block-scoped variable. Can be reassigned but not redeclared.

const

Block-scoped constant. Cannot be reassigned.

if

Executes code if condition is true.

else

Executes code if condition is false.

for

Creates a loop that runs a set number of times.

while

Loops while a condition is true.

function

Declares a reusable code block.

return

Returns a value from a function.

class

Defines a blueprint for objects.

new

Creates an instance of an object.

try

Tests code for errors.

catch

Handles errors from try block.

switch

Evaluates an expression against multiple cases.

break

Exits a loop or switch statement.

3. var vs let vs const

let and const are preferred in modern JS due to block scoping.

var: Redeclaration

Can be redeclared and is function-scoped.

var user = "Ada";
var user = "John";
console.log(user); // John

let: Block Scope

Scoped to nearest { }. Cannot be redeclared.

let score = 10;
if (true) {
  let score2 = 20;
  console.log(score2); // 20
}
console.log(score); // 10

const: Fixed Value

Cannot be reassigned after it is set.

const country = "Nigeria";
console.log(country); // Nigeria

4. Primitive vs Non-Primitive Data Types

Primitives store single values. Non-primitives store collections and references.

Primitive Types

Simple values: string, number, boolean, null, undefined.

let name = "Ada";
let age = 20;
let isActive = true;

Non-Primitive Types

Complex values: object, array, function.

let student = { name: "Ada", age: 20 };
let scores = [70, 85, 90];

Key Difference

Primitives compare by value. Objects compare by reference.

let a = 10;
let b = 10;
console.log(a == b); // true

5. NaN vs undefined

Both mean no value, but for different reasons.

undefined

Variable has no value yet.

let name;
console.log(name); // undefined

NaN

Not a Number. Happens when math fails.

let result = "abc" * 2;
console.log(result); // NaN

7. Difference between Comparison and Logical Operators

We use these to check conditions in JavaScript.

Comparison Operators

Compare two values and give true or false.

let a = 10;
let b = 5;

console.log(a > b); // true
console.log(a == b); // false
console.log(a!= b); // true

Logical Operators

Join two conditions together.

let age = 20;
var hasCard = true;

console.log(age > 18 && hasCard); // true
console.log(age < 18 || hasCard); // true
console.log(!hasCard); // false

Simple Example

Check if you can enter a club. You need to be 18 and above AND have an ID card.

var personAge = 19;
var personHasID = true;

if(personAge >= 18 && personHasID){
  console.log("You can enter the club");
} else {
  console.log("You cannot enter the club");
}

8. Ternary Expression for Grading

A ternary expression is a short way to write if/else. It checks a condition and gives one of two results.

Grade a Student Score

If score is 70 and above = A, 60-69 = B, 50-59 = C, below 50 = F.

var score = 85;

var grade = score >= 70 ? "A" :
            score >= 60 ? "B" :
            score >= 50 ? "C" : "F";

console.log(grade); // A
